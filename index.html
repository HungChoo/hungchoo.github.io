👋 Welcome to space-marine-2-desktop

Space Marine 2 keeps a surprising number of files on your computer. There are game data paths, configuration files, export caches, and export folders — and they are usually tucked away in places that are hard to find. space-marine-2-desktop is a small Windows utility (with macOS support) that acts as a helpful map for all of that.

Instead of digging through hidden folders, you open this helper and it shows you where everything lives. You can quickly reach your configuration files, check your export cache, and open your export folder without typing long file paths or guessing which directory is the right one.

This page walks you through everything in plain language. You do not need to know how to program, and you do not need to understand what a "data path" technically is. If you can click a link and open a folder, you can use this helper.

🧭 What the Helper Does For You

The program is deliberately simple. It focuses on a few jobs and does them well.

Data path discovery. It finds where Space Marine 2 stores its data on your machine and shows you the exact location, so you can open it in one click instead of searching manually.
Configuration files. Your config files control how the game behaves on your computer. The helper points you straight at them and can open the folder that contains them.
Export caches. Export caches build up over time. The helper shows you where they live so you can review them and clear them out when you want to free up space.
Export folders. When you export content, it lands in a specific folder. The helper jumps you there instantly, no file-path typing required.

Everything happens locally on your own computer. The helper reads and opens folders — it does not need an internet connection to do its job after you have it.

🛠️ Troubleshooting Tips

Most first-time hiccups have a simple fix. Work through these in order.

The file will not open. Windows sometimes blocks brand-new downloads. Right-click the file, choose Properties, and look for an Unblock checkbox near the bottom. Tick it, apply, and try again.

Your antivirus gets curious. Newly released files are sometimes flagged simply because they are not widely known yet. You can add an exception for that single file in your security software, or check with the project page first.

Nothing is found on the scan. This usually means Space Marine 2 is installed in an unusual place, or on a different drive. Make sure the game is actually installed on the computer you are running the helper on.

A folder will not open. Some game folders are protected by Windows. If access is refused, right-click the helper and choose Run as administrator for that session.

You moved the helper and it behaves oddly. Keep the file in a normal folder such as Documents or Desktop. Paths with unusual characters or network drives can confuse any Windows program.
